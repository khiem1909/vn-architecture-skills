# vn-architecture-skills

Bộ Agent Skill về **kiến trúc cổ truyền Việt Nam** cho Claude Code, Cursor, Codex và Claude.ai: giúp AI dựng 3D, vẽ, viết prompt ảnh, viết bài và thẩm định nhà ba gian, đình, chùa, đền, nhà rường, nhà sàn… mà không "Trung Hoa hóa". Mọi quy tắc đều kèm nguồn trang và mức tin cậy.

| Skill | Phiên bản |
|---|---|
| [`vietnamese-traditional-architecture`](plugins/vietnamese-traditional-architecture/skills/vietnamese-traditional-architecture/README.md) | 1.2.0 |

## Cài nhanh (Claude Code)

```
/plugin marketplace add khiem1909/vn-architecture-skills
/plugin install vietnamese-traditional-architecture@vn-architecture-skills
```

Cập nhật: `/plugin marketplace update vn-architecture-skills`.

## Cách khác

- **Script** (Claude Code / Cursor / Codex): tải gói `vietnamese-traditional-architecture-v1.2.0.zip` ở [Releases](https://github.com/khiem1909/vn-architecture-skills/releases), giải nén, chạy `install.cmd` (Windows) hoặc `./install.sh` (macOS/Linux).
- **Claude.ai / Claude Desktop**: tải `vietnamese-traditional-architecture.zip` ở Releases → Settings → Capabilities → Skills → Upload skill.

Chi tiết: [CAI-DAT.md](CAI-DAT.md).

## Nguồn

Nội dung là diễn giải có trích trang từ Chu Quang Trứ, Nguyễn Đình Thi & Nguyễn Sỹ Quế, Trần Lâm Biền và văn bản pháp quy; không chép nguyên văn sách. Xem [nguon-phap-ly.md](plugins/vietnamese-traditional-architecture/skills/vietnamese-traditional-architecture/references/nguon-phap-ly.md).
